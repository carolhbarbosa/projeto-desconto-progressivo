# Desconto Progressivo - Loja Online

Programa em Python desenvolvido por Carolina Barbosa para a **Agenda 06** do curso Técnico em
Desenvolvimento de Sistemas (Desenvolvimento de Sistemas I - Estrutura de Decisão).

## O que o programa faz

Solicita ao usuário o valor total de uma compra e calcula o desconto
progressivo a ser aplicado, exibindo o valor do desconto e o valor final a pagar.

## Regras de desconto

| Valor da compra              | Desconto |
|-------------------------------|----------|
| Menor que R$ 200,00            | 5%       |
| De R$ 200,00 até R$ 299,99     | 10%      |
| A partir de R$ 300,00          | 15%      |
